# Mood Analyzer 🧠

An interactive Python script that analyzes the user's daily mood based on simple yes/no questions about their daily habits.

This project serves as a practical review of fundamental Python programming concepts while building a solid foundation for Artificial Intelligence and Machine Learning studies.

---

## 🛠️ Concepts Applied

* **Loops:** `while` and `for` for flow control and continuous execution.
* **Functions:** Modular code structure using `def` and `return`.
* **Data Structures:** Lists for managing questions.
* **Input Validation:** Error handling using `not in` to enforce strict `y/n` responses.
